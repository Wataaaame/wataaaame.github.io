| 设置       | 项目                 | 性能影响  | 作用（标黑为画质优先）<br />【/】性能相同，【-】性能有影响   |
| ---------- | -------------------- | --------- | ------------------------------------------------------------ |
| 细节等级   | 车辆细节等级         | 低        | 控制模型精细度，超高才有好的效果<br />低/中/高-**超高**-极高 |
|            | 环境纹理质量         | 显存      | 影响地面、墙面纹理质量<br />**8G 及以下：高**<br />**12G 及以上：极高**（4k 就不要开【光线追踪全局光照】）<br />低/中/高-超高-极高 |
|            | 环境几何质量         | 中        | 影响建筑、树木、NPC 观众、植被碎石密度<br />NPC 数量：**高（8G）**<br />植被效果：**超高**/极致<br />极低/低/中/高-超高-极高 |
| 反射       | 车辆反射质量         | 帧数      | 车身反射效果：高<br />后视镜精细度：高<br />挡风玻璃反光：中<br />极低/低-中/**高**/超高/极高 |
|            | 屏幕空间反射质量     | 低        | 水面和玻璃反射精度<br />低：启用水面反射（海、湖、小溪、水田）<br />中：增加水洼、水坑、潮湿路面反射<br />高：增加玻璃、窗户、车身表面，并提升反射精度、缓解噪点颗粒<br />关-低/中-高-超高/**极高** |
|            | 光线追踪反射质量     | 高        | **关闭**：8G<br />低：提升明显<br />中：提升玻璃反射<br />低-中/**高** |
| 阴影       | 阴影质量             | 中        | 中：阴影边缘明显闪烁<br />高：缓解一些闪烁<br />超高：基本看不到闪烁<br />极高：更自然<br />关/低/中-高/**超高**-极致 |
|            | 夜间阴影             | 帧数      | 夜间阴影会更真实一点<br />超高：路灯阴影；车灯照阴影<br />极高：月光阴影<br />每个档位降低 4-5 帧，极高额外提高 CPU 占用率 |
| 光照与材料 | 屏幕空间全局光照质量 | 帧数      | 中：光影立体层次感<br />高：更精准的光照效果<br />超高：无明显提升<br />关闭-中-**高**-超高 |
|            | 光线追踪全局光照质量 | 帧数/显存 | 低：没什么提升<br />中：真正开启<br />高：提高细节<br />低-中-高 |
|            | 着色质量             | 低        | 高：水面更真实<br />超高：泥地立体感；整体光影提升<br />会影响树木精度、树木距离：中高一个层次，超高极高更远<br />目前版本：超高极高有点 bug，近秃远精密，调整几何质量缓解<br />低/中/**高**-超高-极高 |
| 性能       | 音频质量             | 低        | 待验证有什么用                                               |
| 其他设置   | 可变地形质量         | 低        | 车轮印子的真实度<br />关闭-**中**-高-超高/极高               |
|            | 粒子效果质量         | 低        | 水花、火星、雨滴、下雨溅起的水滴质量<br />水花：极低无水花；低中高差不多；超高多了些<br />粒子烟雾质量：超高浓厚<br />极低-低/**中**-高/超高 |
|            | 体积雾质量           | 低        | 会导致灰蒙，低中分水岭<br />性能差异不大                     |
|            | 镜头效果             | 低        | 水、雪、泥打湿镜头的效果<br />关闭/低/中/高-超高             |
|            | 动态模糊             | 低        | 产生拖影，营造速度感<br />关闭-**短**-长                     |
|            | 动态模糊质量         | 低        | 性能&效果：低/中/**高**-超高                                 |

- 按照历代经验，【环境几何质量】过高的话，路上的树枝、野草、碎石会更多，意味着在拉力、越野路面上对速度的影响更大
