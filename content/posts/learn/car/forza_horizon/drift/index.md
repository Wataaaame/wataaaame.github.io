# 漂移思路

| 方法   | 驱动                       | 档位  | 场景 | 思路                                                         |
| ------ | -------------------------- | ----- | ---- | ------------------------------------------------------------ |
| 大脚油 | 后驱 > 四驱                | AT/MT | 低速 | 低速进弯，直接打方向，突然大脚给油，后轮扭力过载直接突破抓地打滑，立刻起漂，全程靠油门大小 + 反打方向维持漂移 |
| 大脚刹 | 后驱 > 四驱                | AT/MT | 高速 | 入弯前直线稍微提速；一脚短促重踩刹车，把车身重心猛压到前轮，车尾瞬间变轻；立刻打方向、松刹车补油门，轻飘飘的车尾直接往外甩，顺势起漂<br/>关键点：刹车是点一下就松，不是半踩着不放。 |
| 拉手刹 | 后驱 = 四驱 = 前驱（only） | AT    | any  | 更简单，不用管离合：<br/>低速 30 码左右入弯，打方向<br/>直接猛拉手刹，车尾甩起来<br/>马上松手刹、轻给油、反打方向，稳住车身滑行 |
|        |                            | MT    | any  | 入弯前把车速控在 30～40km/h，挂2 挡，稳住转速<br/>提前往弯里打方向（不用打满，半圈足够）<br/>瞬间踩死离合 + 猛拉手刹拉满（别慢慢拉，要一下拉死）<br/>车尾立刻往外甩，马上反打方向盘对准出弯方向<br/>立刻松手刹，慢补油门，用油门大小控制漂移角度<br/>油给大→飘角变大；收点油→车身慢慢回正 |
| 弹离合 | 后驱 > 四驱                | MT    | 低速 | 入弯降低档→踩死离合→打方向→猛踩一脚油门→瞬间弹开离合，后轮突然爆扭直接甩尾起漂 |
